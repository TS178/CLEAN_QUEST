## 確認できた症状

３種類×３段階を、動きの位相を固定した２つの姿勢で比較した。

- **ウミガメ**：ヒレを振ると、付け根付近に切り出し境界の細い線・隙間が見える。第１形態の手前のヒレ、第３形態の上側のヒレで特に分かりやすい。
- **イルカ**：尾と胴体の接続付近に細い段差・線が見える姿勢がある。第１形態の尾の付け根で確認できる。
- **ヤドカリ**：脚の分割に確認が必要な箇所がある。第２形態の `leg-near-front` は17×18pxしかなく、回転中心は `[1.706, 0]`（画像の右外側）。画像外の回転中心自体は不正ではないが、前脚の一部分だけを動かしている可能性が高い。

現在の描画は切り出したパーツを付け根の周囲で回転させる方式。静止時に一致していても、動くと胴体側に残った境界線や、回転した手足で隠れなくなる箇所が露出する。単純な表示倍率の問題ではなく、切り出し範囲・胴体側の補完・パーツの重なり量を確認する必要がある。

## 次に修正する場合の対象

1. `tools/build-pet-cut.mjs` の各 `poly` と `pivot`、脚の分割結果を元の正面絵と照合する。
2. 胴体側に残る手足の輪郭線と、手足の付け根の重なり量を調整する。
3. ３種類×３段階で、静止姿勢だけでなく振れの両端・中間、左右の向きでも確認する。
4. 管理者画面に加えて、ホーム・すみかで装備を付けた状態を確認する。

今回の指示ではこれらは実施していない。生成された設定だけを手編集すると再生成で失われるため、修正を行う際は生成元も揃える。
