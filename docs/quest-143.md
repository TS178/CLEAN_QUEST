# しかクエ 1.43

## 変更

- 承認済みのカメ（shoot-master-turtle-v2）と、実キャラクターに合わせたヤドカリ（beach-hero-hermit-v3）の称号を512pxの透過WebPとして収録。
- シュート★3＝1,200点以上・ミスなし。バスターズ★3＝18,000点以上（PERFECT不要）。各ゲームの最高スター数を保存し、次回プレイ・再読込・バックアップ後も達成を保持。称号は従来のミッション画面の通知・コレクション・運営QRに対応。
- 旧保存データは直近の★3結果から最高スター数を補完。バスターズは最高点からも判定可能。旧版のシュートで過去のノーミス結果が失われている場合は、最高点だけで★3と推測しない。
- 銀色・落ち着いた赤の作成済みアイコンを使用。PNG/ICOは1.42で採用済みのファイルと一致を確認し再配置、旧SVGファビコンもSQへ統一。アイコンURLに版を付与。manifestのname/short_name、Apple用タイトルを「しかクエ」に変更。アプリ内ブランドはSHIKA QUESTのまま。
- 最初から3匹を横並びで表示。暗い背景・各キャラクターへのスポットライト、指定の見出し。タップ時にジャンプし、説明付きの「はい／いいえ」を表示。「いいえ」は保存せず選び直し、「はい」は名前入力へ。孵化演出は「なかまになったよ」に置換。既存の複数匹育成にも対応し、すでにいる種類は再選択不可。
- バスターズは動的ビューポート全体からヘッダー・操作部の実サイズを差し引くflex構成。説明・ゲーム・結果の各状態に合わせて表示を調整。
- 大型2種類は専用SVGに変更。袋の悪魔は角・羽・尻尾、ボトルのどろぼうは覆面・しま模様・袋。通常のゴミ画像＋王冠を廃止し、サイズと10回タップのルールは維持。
- 新素材をサービスワーカー1.43の事前キャッシュに追加。
