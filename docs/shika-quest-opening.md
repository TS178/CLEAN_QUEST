# SHIKA QUEST 起動演出（1.42）

SHIKA COLLECTIONと同じ増穂浦の写真を背景に、イルカ・ウミガメ・ヤドカリが動き、消えた後に銀色と落ち着いた赤のロゴが現れます。約7秒でスタートボタンを表示します。ようせいの間隔を広げ、低い画面では大きさも調整しています。

- `js/opening.js` / `css/opening.css`：演出本体。スキップ、画像失敗時の代替表示、非表示タブでの一時停止、OSの動き軽減設定に対応。
- `js/startup.js`：スタート後に既存の `BCT.start()` を1度だけ呼び、初回はたまご選択、育成中はホームへ進む。アプリ内の動きを減らす設定にも対応。
- `assets/opening/`：背景、銀色・赤のロゴ、既存の第1段階の笑顔素材。
- `icons/`：PWA用の全体ロゴと、小さいタブ用のSQファビコン。
- `index.html` / `manifest.json`：表示名をSHIKA QUESTへ統一。PWAのid・scope・start_urlおよび保存キーは変更しない。
- `service-worker.js`：1.42へ更新し、演出素材を事前キャッシュ。既存ユーザーは従来の更新案内から更新する。

演出中はアプリ本体を非表示・inertにし、背後の操作を防ぎます。スタート後はフォーカスを表示画面へ移します。演出の初期化自体に失敗した場合は通常のアプリ起動に進みます。

保存データの形式やキー、既存のミッション・ようせい・すみかの操作は変更していません。

検証：`node --test tests/logic.test.mjs tests/update.test.mjs`、`node tests/e2e/opening.mjs`。
ブラウザ検証は専用プロファイルと、公開ファイルの許可リストだけを配信する一時サーバーを使用します。
