# 志賀町アイテムの組み込み（1.22）

## 対象

承認済みの原画６点をゲーム用WebPへ変換し、ショップ・きせかえ・すみか・写真書き出し・オフライン用の画像に反映。
原画は `assets/design-proposals/shika-items-20261016/` に保存。ベンチは直線的な最終版で、手前の赤い椅子なし。

差し替え２点は既存ID・価格を維持し、旧購入情報と装着状態を継承。新規４点の価格は既存商品の価格帯に合わせた。
３点の置物は全種類で購入・配置でき、種類変更時も配置を継承。専用の家具は従来どおり対象の種類だけで使える。

## 修正した互換性

既存の `placeHome`・保存データの検証・種類変更時の配置整理は、すべての家具に `only`（専用の種類）がある前提だった。
共通置物を追加するだけでは配置が拒否され、再読み込み・種類変更で配置情報が消えるため、３か所とも「onlyがある商品に限って種類を照合する」に統一した。

画像は既存方式と同じ埋め込みWebP。SVGを画像として書き出しても外部画像参照にならず、オフラインでも描画できる。
既存の全画像と比較し、変更されたエントリーは対象６点のみ、削除なし。全埋め込みデータと対応WebPの一致も確認。

## 再生成と検証

- `python tools/pack-shika-items.py`（Pillowが必要）。既存の原画アトラスを再生成した場合も最後に実行する。
- `node --test tests/logic.test.mjs tests/pet-rig.test.mjs tests/ar-math.test.mjs`
- `node tests/e2e/shika-items.mjs`
- `node tests/e2e/habitat-art.mjs`
- `node tests/e2e/startup-diagnostics.mjs`
- `BCT_URL=http://127.0.0.1:8766/` を設定し、`node tests/e2e/run.mjs` と `node tests/e2e/iphone.mjs`。

ブラウザ検証は独立したEdgeプロファイルを使用。利用者の保存データは変更していない。
撮影は仮想カメラ、iPhone向けの確認はEdgeのUA・画面サイズエミュレーションであり、iOS実機のカメラ・WebKit動作の保証ではない。

### 再現していない初期化エラー

最初に全体テストとiPhoneテストを並行実行した際、コンソールに `$ is not a function`（home.js等）、`BCT.start is not a function` が記録された。操作項目自体は通っているが、コンソール検査で失敗と判定。
その後、iPhoneテストの単独再実行・初回読み込みと再読み込み４回の通信／例外診断・全体テストの単独再実行はいずれもエラーなし。
**原因は未確定で、修正済みとは扱わない。** 初期化処理を推測で書き換えてはいない。診断スクリプト `tests/e2e/startup-diagnostics.mjs` を残した。
