# 原画を使ったペットの部位アニメーション

`preview-pet-motion.html` で3種類×3成長段階を比較できる。「動きを表示」で停止、「まばたきを見る」で確認する。プレイヤーの保存データは変更しない。

## 実装

`js/pet-motion.js` は既存の透明画像をGPUで局所的に変形する。イルカは尾びれと胸びれ、カメは左右のひれ、ヤドカリは脚とはさみに別々の重み・周期・位相を設定。部位の付け根で変形を滑らかに弱め、切り離したパーツの隙間を作らない。

元の通常顔・笑顔の目の領域だけを合成してまばたきする。口・頬・胴体は表情切り替えで差し替えない。自然な間隔と短い二度まばたきを含む。原画ファイルは変更していない。

- ホーム・住処・きせかえなどのインラインSVGを自動で拡張。装備・模様・おもちゃは既存のSVGレイヤーのまま。
- ARは `createComposite()` のCanvasをThree.jsテクスチャとして更新。元のレイヤー順・装備・ポーズを維持。
- 写真の書き出しは従来の静止SVGを使用。
- 1個の共有WebGLコンテキスト、最大30fps。画面外・非表示タブでは描画を停止し、取り外した要素は解放。
- OSとアプリの「動きを減らす」設定に対応。WebGLが使えない場合は元の静止画を表示。
- ゲーム数値・育成・購入・保存データには触れない。

`RIGS` の座標は `assets/art-source/evolution-*.png` 上のピクセル座標。cropは `tools/pack-pet-art.mjs` のトリミング結果に一致させている。

## 検証

- `node tests/e2e/pet-motion.mjs`：18表情の部位変形、目以外の不変性、原画との色差、装備合成、停止・再開・解放、保存データ。
- `BCT_URL=http://127.0.0.1:8766/` を指定して `node tests/e2e/ar.mjs`：仮想カメラと傾きセンサーでAR操作。実機WebXRの床認識は別途実機確認が必要。
- `node tests/e2e/beach.mjs`：購入・ごはん・進化・住処の配置。
