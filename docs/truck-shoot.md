# ゴミしゅうしゅうしゃ シュート！（1.30）

ミッションのカードから遊べる45秒のミニゲーム。ホームのゴミ、清掃記録、育成経験値には影響しません。
手前が海・砂浜、奥が陸の道路です。ゴミを下へ引いて離すと陸側へ飛びます。
逆向きの操作・短すぎるドラッグ・タッチキャンセルでは発射しません。

## ルール

- 1成功100点。連続成功の追加点は20、40、60、80、100点まで増えます。
- 失敗でコンボが途切れます。得点と所持メダルは減りません。
- 成功0回：星なし、0枚。1回以上：★1、10枚。600点以上：★2、25枚。
- **1,200点以上かつミスなし：★3（パーフェクト）、50枚。**
- 最大コンボ3回ごとに追加1枚、上限10枚。毎回の完了プレイに報酬があります。
- 45秒で新規発射を止め、時間内に発射した最後の1個が着地してから結果を表示します。
- 画面非表示、ウィンドウのフォーカス喪失、画面移動で一時停止。ミッションから再度開くと続行できます。
- 「このゲームを やめる」は未完了のラウンドを破棄します。ページ再読み込みではプレイ途中の状態は復元しません。
- 音は初期OFF。うごきをへらす設定は泡・紙吹雪・妖精のジャンプを抑えます。
- キーボード：CanvasへTabで移動し、左右キーで方向、上下キーで強さ、スペースで発射、Escで一時停止。

## 構成

- `js/truck-shoot-physics.js`：定数、左右/奥行き/高さの軌道、移動車両、得点、ラウンド更新。ブラウザDOMなしでテストできます。
- `js/truck-shoot-view.js`：Canvas 2Dの背景・収集車・ゴミ・エフェクト。外部画像や物理エンジンへの依存なし。
- `js/truck-shoot.js`：入力、画面ライフサイクル、Web Audio、既存妖精アート、リザルト、報酬保存。
- `css/truck-shoot.css`：ゲーム画面。所持メダルのヘッダーは残し、プレイ画面の下部タブは隠します。

下降して投入口の高さを横切った時刻を解析的に求め、その時刻の車の位置と比較します。
描画が遅くても判定がすり抜けず、予測線と本番は同じ軌道関数を使います。

## 保存

`game.finishTruckShoot(round)`が成績から報酬を再計算し、`store.transact()`で台帳と成績をまとめて保存します。
台帳キーは既存形式の`イベントID:truck:runId`。同じラウンドの再保存・結果再表示では重複付与しません。
Web Locks対応ブラウザではゲーム報酬の保存要求を直列化します。
保存失敗時はメモリと台帳を巻き戻し、同じ結果を再試行できます。成功するまで再挑戦ボタンは無効です。

`state.truckShoot`にプレイ回数・最高点・最大コンボ・直近の結果を保存します。
旧データでは初期値を補い、バックアップにも含めます。XPは0、ホームの`beach`には触れません。
メダルの飛翔は既存の`coinFly`を利用し、保存確定後に表示を更新します。

## 検証

```
node --test tests/truck-shoot.test.mjs tests/logic.test.mjs
node tests/e2e/truck-shoot.mjs
```

E2Eは一時的なローカルHTTPサーバーとテスト用Edgeを起動します。実際の45秒ラウンド、タッチ操作、
取り消し、一時停止、画面移動、報酬、再読み込み、バックアップを検証します。
スクリーンショットは`tests/e2e/out/truck-shoot-*.png`です。
