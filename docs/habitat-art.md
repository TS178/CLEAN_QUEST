# 住処・追加ショップアイテムのデザイン

2026-10-11。内蔵 ImageGen で制作したイラストを、住処用家具9点・ごはん3点・背景3種類に使用。

- ラグーン・オーシャン：透明な浅瀬、白い岩、サンゴと小さな滝。
- アクア・ガーデン：アマモ、海の草花、光の差す砂地の庭。
- ビーチ・ヴィレッジ：貝がらの家、流木の橋、浜辺の広場。

`preview-habitats.html` に全点のデザイン一覧。保存データは読み書きしない。
アプリのショップ・購入画面・住処・エサトレイには `js/habitat-painted-art.js` で反映。
キャラクターの原画、ゲームの数値・購入条件・配置保存・アクションは変更していない。

## 画像と再生成

- 原本：`assets/art-source/habitats/*.png`
- 各画像の完全なプロンプト・生成元パス：`assets/art-source/habitats/generation-record.json`
- 軽量画像：`assets/habitats/*.webp`（家具とごはん512px、背景1200×900px）
- オフライン用埋め込み：`js/habitat-sprites.js`

HTTPサーバー起動中に `node tools/pack-habitat-art.mjs` で再パックできる。
`BCT_URL` でサーバーURLを指定可能（既定 `http://127.0.0.1:8766/`）。
パッカーは透明余白のトリミング・縮小・WebP圧縮だけを行い、原本の色や描画は変更しない。
サービスワーカーは埋め込み画像のJSを保存するので、初回読み込み後は圏外でも表示できる。
