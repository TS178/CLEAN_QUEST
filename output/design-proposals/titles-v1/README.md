## デザイン方針

小学生が集めたくなる、ぷっくりしたシール／ピンバッジの質感。形と色の両方で7種類を見分けられるようにします。丸い輪郭、明るいミント・サンゴ色・黄色・ラベンダー、白いハイライトを共通にします。名称は絵の外に大きく読みやすく表示します。

画像右下は未獲得状態のイメージです。8個目の称号ではありません。未獲得も薄いパステルで輪郭が分かるようにして、獲得すると鮮やかな色になる案です。進捗バーは既存の進捗値がある称号のみを対象とする想定で、見本のバーは実データではありません。

獲得時はバッジを大きく表示し、一度だけふわっと弾む演出と少量のきらめき。常時点滅はさせず、動きを減らす設定に合わせる想定です。

これは絵柄・配色・質感を判断するための見本です。採用後に小さい実表示での線・装飾の整理、ペットの既存デザインとの整合、未獲得／獲得状態の仕上げを行います。
