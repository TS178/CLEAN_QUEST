コンセプト：探検隊がごみを分別してペットを育てていく。

- そだておや賞：中央の大きなピンクのハートを、左上のイルカ・右上のウミガメ・下中央のヤドカリが囲み、一緒に支える構図。

- 未獲得見本も新しい分別デザインに更新。
