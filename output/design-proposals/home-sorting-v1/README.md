# ホーム画面・分別ごみ箱とごみのデザイン案

提案のみ。ゲーム本体・分類・出現間隔・操作・保存データは変更していません。

称号デザインv3と同じ、丸い輪郭・ぷっくりした立体感・明るい色・柔らかな白いハイライトで統一。ごみ箱はアイボリーの縁、持ち手、下部の小さな波模様を共通にし、投入口を大きく見せます。

| ごみ箱 | 色とマーク | 対応する既存のごみ |
| --- | --- | --- |
| プラスチック | 青、ボトルと袋 | ペットボトル・ビニールぶくろ・ロープ |
| かん・びん | 黄、缶とびん | かん・びん |
| もえるゴミ | コーラル、紙と枝 | きのえだ・かみくず |

ごみはへこみ・折り目・しわで使用済みの物として描写。顔やメダルの縁を付けず、ペットや報酬と見分けられるデザインです。ごみ箱のマークとごみの形を対応させ、色以外でも分類を見分けられるようにします。

現行表示はごみ箱58×66px、ごみ54×54px。採用後の素材化では、このサイズで読める輪郭とマークに調整し、透明背景の個別画像を作成する想定です。今回の成果物は比較用の提案ボードで、実装用の透過素材ではありません。
