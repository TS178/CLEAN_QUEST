# ビーチクリーン探検隊

親子で参加するビーチクリーンイベント（想定：30組・約100名）のための、スマホ向けWebアプリ（PWA）です。
**ホーム画面に追加したときの名前は「クリーンクエスト」**（`manifest.json` の name・short_name、iPhone は `apple-mobile-web-app-title`）。ブラウザのタブの題名は「ビーチクリーン探検隊」のままです。
テーマは「海がきれいになると、海の仲間が喜んで育つ」。自分の **うみの ようせい**（イルカ・ウミガメ・ヤドカリの姿をした海の妖精）を育てます。

**遊びの流れ（メインループ）**
1. 時間がたつと、ホームのビーチが よごれる（よごれ度1〜3。ようせいが困り顔になる）
2. 流れついたゴミを **分別ゴミばこへドラッグ／スワイプ** して捨てる → **クリーンポイント**
3. ポイントで **エサ（アクアドロップ）** や **すみかのアイテム**、着せ替えを買う
4. エサをあげて **けいけんち** をためる → ようせいが進化（こども → 進化1 → 最終進化）

**うみクイズ** と、実際のゴミを撮影して記録する **そうじミッション** は、学びと **ボーナスのポイント** の場です（けいけんちは ごはん（エサ）からだけ）。
着せ替え・AR で なでる／あそぶ・記念撮影・すみか でも遊べます。

- 対象：小学生とその保護者（画面の文字はひらがな中心）
- 使い方：**1組につきスマホ1台**（保護者のスマホ）。1組＝1「たんけんたい」
- ビルド不要の静的サイト（HTML / CSS / JavaScript のみ）。GitHub Pages にそのまま置けます
- 放置による空腹・病気・能力低下などはありません。ビーチがよごれると困り顔になりますが、けいけんち・ポイント・なつきどは減りません（掃除すればすぐ笑顔）
- 画面の中の海の変化はゲームの演出です。実際の水質や清掃成果を測っているわけではありません

### OpenStreetMap タイル利用規約を守るために（変更しないこと）

[タイル利用規約](https://operations.osmfoundation.org/policies/tiles/) に違反すると、予告なく地図が使えなくなります。

- 地図の右下に「© OpenStreetMap contributors」を常に表示する（消さない・たたまない）
- タイルの事前ダウンロード・オフライン保存をしない（`service-worker.js` はよそのサイトへの通信に一切手を出しません）
- リファラーを消す設定（`referrerpolicy="no-referrer"` 等）を入れない
- ズームは18まで
- 無償・保証（SLA）なしのサービスです。止まった場合、アプリは自動で「記録一覧＋集計表」の表示に切り替わります

## 🚀 公開のしかた（GitHub Pages）

1. GitHub で **公開（Public）** リポジトリを作る
2. このフォルダの中身をリポジトリの直下に置いて push する（`.nojekyll` という空ファイルも忘れずに）
3. リポジトリの **Settings → Pages** で、Source を **Deploy from a branch**、Branch を `main`・フォルダを `/ (root)` にして保存
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます

- **カメラ（記念撮影）と位置情報は https でないと動きません。** GitHub Pages は https なので問題ありません
- アプリを書き換えたら、`service-worker.js` の `APP_VERSION` を必ず上げてください（**「1.○○」の形**。例：`1.15` → `1.16`。設定の画面に「バージョン 1.15」のように そのまま出ます）。上げないと、すでに開いたことのある端末に新しい版が届きません
- 新しい版が届くと、アプリに **「あたらしい バージョンが あります」** が出ます（SHIKA COLLECTION と同じ。`js/update.js`）。「こうしん する」で すぐ新しい版にして開き直します。勝手には開き直しません（クイズ・さつえい・AR・しんかの演出・ほかの おしらせの あいだは、終わるまで待ってから出します）。「あとで」を選んだときは、設定のバージョンの下に「こうしん する」ボタンが出ます。アプリを開いたとき・10分以上たってから戻ってきたときに 新しい版がないか確かめます。育てたデータは そのまま残ります
- **イベントの日付が決まったら** `js/config.js` の `event.days` に書いてください（例：`["2026-11-08"]`）。その日は0時〜24時、**ちず と ばしょの きろく** が自動で使えます（下の「ちず・ばしょの きろくは イベントの日だけ」）。いまは空（日付では開かない）です
- イベントごとに `js/config.js` の `event.id`（と `event.name`）を変えてください。そうじミッション・クイズの報酬は「イベントID＋ミッションID」で1回だけなので、同じ端末で次のイベントに参加したときにまたもらえます

## 📅 イベント当日の流れ

1. **受付**：`operator.html` の **「⓪ 受付用 QR」** を印刷して掲示 → 保護者のスマホで読んで開いてもらう（このQRで開くと、その日の24時まで ちず・ばしょの きろく が使えます。`event.days` にイベントの日付を書いてあれば、QRでなくても自動で使えます）
   - ホーム画面に追加したアプリ（とくに iPhone）は Safari と保存場所が別なので、アプリの「ひろう」→「ちず」→ **「うけつけの QRコードを よむ」** でもう一度読んでもらいます（日付を書いてあれば不要）
   - できれば「ホーム画面に追加」してもらう（iPhone：共有ボタン→ホーム画面に追加／Android：メニュー→ホーム画面に追加）
   - **電波の良い受付で一度開いておけば、浜辺で圏外になっても動きます**（地図を除く）
2. **たまごを選ぶ** → ようせいの名前（入れなくてもよい）とたんけんたいの名前を入れる（本名は入れないよう案内してください）。おいわいに「あかい リボン」をプレゼント
3. **ゴミ拾い**：「ひろう」でゴミを撮影 →「ばしょも きろく する？」に答える → 種類を選んで記録。**種類ごとに最初の1回** がそうじミッション（ボーナスのポイント）
4. **ホームのビーチのお掃除・エサやり**：休憩中などに。ビーチは15分ごとによごれます
5. **うみクイズ**：休憩中などに
6. **ショップ・すみか・きせかえ・記念撮影**：たまったポイントで好きなアイテムを
7. **終了時**：「ミッション」→「🎉 イベント しゅうりょう QRコード」（うみクイズの上。**イベントの日だけ出ます**。`event.days` の日か、受付の QR で開いた端末）を運営に見せてもらう
8. **運営**：`operator.html` で全員のQRを読み取り → 集計・CSV書き出し

### 運営用画面（operator.html）

`https://<ユーザー名>.github.io/<リポジトリ名>/operator.html` を運営用の端末で開きます（参加者の画面からはリンクしていません）。

- **⓪ 受付用 QR**：アプリの URL に あいことば（`js/config.js` の `event.openKey`）を付けた QR です。「この QR を 印刷する」で QR だけ印刷できます
- 「📷 カメラ起動」→ 参加者のQRを枠に入れると自動で読み取ります（同じ端末のQRは **上書き**。二重に数えません）
- **清掃の量や成績で順位をつけない方針** のため、順位の列・上位の色分けはありません。並び順は「読み取った順」「隊の名前順」だけです
- 合計（隊数・人数・ゴミ・クイズ・そうじミッション・称号）、種類別のゴミの数、称号ごとの獲得隊数を表示
- 「CSV を書き出す」：Excel でそのまま開けます（BOM付きUTF-8）。**「全部消す」の前に必ずCSVを書き出してください**

### イベント終了QRの中身（v2）

`{"v":2,"app":"bct","ev":イベントID,"id":端末ID,"tm":隊の名前,"n":人数,"pet":種類,"pn":ようせいの名前,"lv":レベル,"xp":けいけんち,"qz":クイズクリア数,"cm":そうじミッション数,"rc":ゴミの記録数,"tr":{種類:個数},"bd":[称号ID],"t":作成時刻}`

**位置情報は含めていません**（子どもの行動範囲がわかってしまうため）。前の版（v1・クリーンPt方式）のQRは運営画面が「版が違う」と案内します。

## 🎮 ルール（数字はすべて `js/config.js` で変えられます）

### 配分の切りかえ（イベント用 ／ 長く遊ぶ用）

`js/config.js` の `const pace = "event";` を `"long"` に変えるだけで、長く遊ぶ配分になります。

| 配分 | 最終進化までの目安 | ビーチが よごれる間隔 | 進化1（Lv3） | 最終進化（Lv5） |
|---|---|---|---:|---:|
| `event`（いま） | イベント当日 2〜3時間 | 15分ごとに1段階 | 150 | 450 |
| `long` | 約1週間（毎日 少しずつ） | 3時間ごとに1段階 | 400 | 1400 |

※ `long` の数字は目安です。実際に遊んでもらって調整してください。

### ビーチの お掃除（分別）

- 時間がたつと、ゴミが3こずつ流れつきます（よごれ度1〜3、最大9こ）。アプリを閉じていたあいだの分もまとめて進みます（3で止まる）
- ゴミばこは3つ：**青＝プラスチック**（ペットボトル・ビニールぶくろ・ロープ）、**黄＝かん・びん**、**赤＝もえるゴミ**（きのえだ・かみくず）。ゴミのうしろに入れるゴミばこの色の丸があるので、色で分けられます
- 捨て方：**ドラッグして ゴミばこに はなす**／**ゴミばこの方へ はじく（スワイプ）**／**タップで選んで ゴミばこをタップ**
- 正しく捨てると **+5 ポイント** と ようせいが大喜び。まちがえても何も減らず、正しいゴミばこが光って教えます
- ゴミばこは **よごれている あいだだけ** 出ます。きれいになると（ゴミを のみこむ演出のあと）なめらかに しまい、また よごれると なめらかに出てきます
- はじめてビーチがきれいになったとき、ようせいが「うみクイズ」にさそいます
- ※ 画面の中の よごれはゲームの演出です。実際の海の水質や清掃成果を測っているわけではありません

### エサ（アクアドロップ）

| エサ | 値段 | けいけんち | |
|---|---:|---:|---|
| アクアドロップ（青） | 10 | +10 | まいにちのごはん |
| シャイニードロップ（緑） | 40 | +50 | ちょっと とくべつ |
| レインボードロップ（虹） | 140 | +200 | 進化のまえに |

- ショップの「エサ」で買い、ホームで **ようせいへドラッグ**（またはタップで選んで ようせいをタップ）するとあげられます。種類ごとに専用の喜ぶ動き（イルカ：大ジャンプ／ウミガメ：ゆらゆら／ヤドカリ：貝ごとはねる）
- 高いエサほどおとく。クイズを全部とけても（300ポイント）、それだけでは最終進化に届きません

### ミッションと報酬（ボーナスのポイント）

| ミッション | ポイント | 回数 |
|---|---:|---|
| うみクイズ（15問） | 20 | 各問の **はじめての正解だけ**。まちがえても減らない。解説を見て再挑戦できる。クリアした問題は ◀ ▶ で こたえと解説を見かえせる |
| そうじミッション「〇〇を みつけた」（実際のゴミの記録） | 20 | **ゴミの種類ごとに1回**（ペットボトル・プラスチック・あみ/ロープ・うき/ブイ・かん・きのざい・そのほか の7種類） |

- けいけんちは出ません（けいけんちはエサだけ）
- **びん** は割れたガラスでけがをするおそれがあるため、報酬の対象外です（記録・地図・称号・運営集計には入ります）
- 2件目以降の記録には報酬はありません（地図・称号・運営集計には入ります）。量で競わせないためです
- 報酬は「イベントID＋ミッションID」で記録するので、連打・再読み込み・複数タブでも二重にもらえません

### ようせいの成長（けいけんちの累計。イベント用の配分）

| Lv | 呼び名 | 累計けいけんち | 見た目の段階 |
|---|---|---:|---|
| 1 | うまれたて | 0 | こども |
| 2 | げんきっこ | 60 | こども |
| 3 | なかよし ようせい | 150 | **進化1** |
| 4 | うみの ゆうしゃ | 280 | 進化1 |
| 5 | うみの まもりがみ | 450 | **最終進化** |

- 進化は全2段階（こども → 進化1 → 最終進化）。見た目が変わるとき（Lv3・Lv5）は進化アニメ（①浮いてゆっくり回る →②だんだん速く →③ピカッと光って新しい姿）。それ以外のレベルアップは短いおいわい
- 1回のエサで複数のレベルを越えても、最後のレベルまで1回の演出で進みます。着せ替えはそのまま

### なつきど（なでる）

- 「なでる」5回で1だん、最大3だん。けいけんち・ポイントは出ません
  - ホームの「あそぶ」→ **AR** で、ようせいをタップ または 指でこする（下の「AR で なでる・あそぶ」）
  - ホームの池の中のようせいをタップしても なでられます（カメラを使わない いつもの遊び方）
- 演出中の連打は1回に数えます
- 1だん：えがお ／ 2だん：こちらに近づく ／ 3だん：とくべつな喜び方（くるくる回ってきらきら）

### おもちゃ と ポーズ

- おもちゃ（ビーチボール・あわの リング・かいがらの がっき）はショップで買い、ホームの「あそぶ」→ **AR** で使います。消耗しません
- 演出が最後まで終わった1回を数えます（途中で画面を離れたら数えない）。**同じおもちゃで3回** 遊ぶと、記念撮影のポーズを覚えます
- ポーズ「つうじょう」「えがお」は最初から使えます

## 🪄 AR で なでる・あそぶ（ポケモンGO のように）

ホームの「あそぶ」を押すと AR 画面になります。カメラの向こうに ようせいが いるように見え、なでたり、おもちゃを投げたりして遊べます（なでる・おもちゃは どちらも同じ AR 画面でできます）。

**はじめに毎回「あんぜんの やくそく」を表示します**（歩きながら使わない・周りを確かめる・海や水辺・岩場の近くでは使わず大人と一緒に・ゴミ拾いの途中はしまう）。

| 方式 | 対応 | しくみ |
|---|---|---|
| ゆかに おく AR（おすすめ） | Android の Chrome ＋ ARCore 対応機種（対応しているときだけボタンが出ます） | WebXR で床を見つけ、白い輪が出た所をタップすると そこに置く。歩いて近づいたり回り込んだりできる |
| カメラで AR（ジャイロ式） | iPhone・ほかの Android | カメラ映像の上に表示。スマホの向きを変えても ようせいはその方向にとどまって見える（iPhone は傾きの許可を求めます）。傾きがとれない端末では画面に固定 |
| カメラを つかわない | すべて | ホームの いつもの遊び方（おもちゃを選んで遊ぶ。ようせいは池の中でタップすると なでられる） |

- **なでる**：ようせいを **タップ** または **指でこする**。演出中の連打は1回に数えます
- **あそぶ**：下に並んだ おもちゃ を使います（持っているものだけ）
  - ビーチボール：**タップでまっすぐ投げる／上にはじくと その向きに投げる**。外れたら ようせいが追いかけて、遊び終わると元の場所に戻ります（だれでも遊べるように、外れても1回に数えます）
  - あわの リング：泡がようせいに届いて、くぐる・ジャンプする
  - かいがらの がっき：音に合わせて おどる
  - 演出が最後まで終わった1回を数え、**同じおもちゃで3回** 遊ぶと撮影のポーズを覚えます。途中で戻ったら数えません
- 「📍 ここに よぶ」：いま見ている方向（床に置く AR では白い輪の所）に ようせいを呼び直します
- 画面を離れたり、アプリを裏に回したりするとカメラ（AR）を止めます。カメラ映像はどこにも送信・保存しません
- three.js（約2.1MB、圧縮配信で約420KB）は AR 画面を開いたときに読み込みます（オフライン用に Service Worker が保存）

## 📸 いっしょに さつえい（AR風の記念撮影）

カメラの映像に、育てた姿・着せ替え・ポーズを反映した2Dのようせいを重ねて撮影します（床への固定や距離の測定はしません）。

1. ホーム →「📸 さつえい」
2. 「カメラで とる」を押したときに初めてカメラの許可を求めます
3. ようせいは **ドラッグで移動**、**ピンチ または スライダーで大きさ**
4. ポーズ（覚えたものだけ）・フレーム・「なまえ・イベント・ひづけ」の表示オン/オフを選ぶ
5. シャッター → できあがりを確認 →「ほぞんする」（共有シートが使える端末は共有シート、それ以外はダウンロード）／「とりなおす」

- カメラが使えない（許可しない・カメラがない・https でない）ときは、理由を表示して **「しゃしんを えらぶ」** で同じように作れます（「うみの はいけい」は 2026-10-13 に なくしました）
- **カメラの許可がない** ときは「📷 カメラを つかわせてね」と、iPhone／Android それぞれの許可のしかたを出します（`js/camera-permission.js`。AR も同じ）。「もういちど ためす」で もう一度カメラをためし、まだ許可がなければ **許可が出るまで同じおしらせを出します**。ブラウザが許可の変化を教えてくれるときは、許可されたら すぐカメラが動きます。※ スマホのブラウザは、一度「許可しない」を選ぶと アプリから許可の画面を出し直せないため、ブラウザの設定で許可してもらいます
- 画面はスクロールなしで おさまるように、写真の枠の大きさを画面の高さに合わせます
- 前面カメラは、画面も保存画像も鏡のように左右反転します（ようせいと文字は反転しません）。画面と保存画像は同じ 3:4 で、位置・大きさ・フレームが一致します
- 画面を離れたり、アプリを裏に回したりするとカメラを止めます
- カメラ映像・写真はどこにも送信しません。できた画像は利用者が保存するまで端末のメモリの中だけにあります
- 保存に失敗したときも、できあがりの画像は残るので「画像を長押しして保存」を案内します

## 🐬 パーツで うごく ようせい（ホームの池・すみか）

ようせいが **移動している あいだ** は、パーツ分けした絵（`assets/pet-parts/`）を重ねて、素の JavaScript で動かします。外部のサービス・ライブラリ・有料ツールは使いません（`js/pet-rig.js`）。

- 各パーツは 付け根（`transform-origin`）を中心に、`requestAnimationFrame` で サイン波の 回転を します。親子（胴体 → 尾の付け根 → 尾びれ など）は入れ子にして、親が回ると子もついてきます
  - イルカ：尾びれを上下に振る。胴体は逆の位相で わずかに傾く
  - ウミガメ：前ヒレは大きく ゆっくり、後ろヒレは小さく、頭は軽く上下
  - ヤドカリ：対角の脚を組にして交互に動かし、歩幅に合わせて胴体が上下
- **移動の速さ** に合わせて、ヒレ・脚の速さと振れ幅が変わります（止まっているときは小さく ゆっくり）
- **向きを変えるとき** は パーツのまま一瞬で反転します（正面の絵を はさむと一瞬ちらつくため。背面の絵ができたら `turnMs` で はさめます）
- **向きを変えるのは 30秒に1回ほど** です。それまでは向いている ほうへ少しずつ進みます（上下には自由に動く）。すみかで自分から遊びに行くのも前にあるアイテムだけで、タップされたアイテムには うしろでも振り向いて行きます
- 帽子・こものは 正面の絵と同じ付け根で **頭・胴体のパーツに付く** ので、いっしょに動きます（ウミガメは頭に付きます）
- 次のときは **正面の絵**（いままでの絵と動き）にもどります：なでる・あそぶ・ゴミやエサで よろこぶ・すみかで止まっている／アイテムで遊んでいる・「うごきを へらす」設定
- 正面の絵と同じ位置・大きさに出すので、切りかえても ずれません
- パーツ画像は 自分の種類の分（約1.2MB、ほかの段階も）だけ ホームで先に読み、Service Worker が保存します（進化しても圏外で表示できる）。読めないときは正面の絵のままです

小さいスマホ（池が ひくい画面）では、ホームの ようせいの枠を すこし小さくし（画面の高さの26%・幅の52%・190px の いちばん小さい大きさ）、池の上に はねる分の すきまを あけて動き回ります。はねても頭が池から はみ出しません。

### 設定（`js/pet-rig-config.js`）

付け根の座標・振れ幅・周期・重ね順は、種類ごとに このファイルにまとめてあります。

| 項目 | 意味 |
|---|---|
| `cycle` | 1秒あたりの回数（`idleHz`：止まっているとき 〜 `moveHz`：ふつうに動いているとき） |
| `idleAmp` | 止まっているときの振れ幅の割合 |
| `parts.<パーツ>.pivot` | 付け根（回転の中心）。パーツの画像に対する割合 |
| `parts.<パーツ>.swing` | 振れ幅（度）・周期の倍率・位相 |
| `parts.<パーツ>.z` | 重ね順（マイナスは胴体のうしろ） |
| `stages.<段階>.place` | 置き場所。胴体は元の絵の上の位置と大きさ、ほかは「親の どこに付けるか（`at`）」と角度・大きさ |
| `head`（ウミガメ） / `bob`（ヤドカリ） | 頭の上下 ／ 胴体の上下 |
| `equipShift`（イルカ） | 帽子・こものを パーツ表示のときだけ ずらす（リボンを首もとへ） |
| `stages.<段階>.tint`（ヤドカリ） | パーツの色を正面の絵に近づける補正（鮮やかさ・明るさ） |
| `common.speedRef` / `turnMs` | 「ふつうに動いている」速さ ／ 振り向くときに正面の絵を見せる時間（いまは 0＝はさまない） |
| `common.turnEveryMs` | 向きを変える間隔（いまは 30000＝30秒に1回ほど） |

位置の確認と調整は `preview-pet-rig.html`（元の絵をうすく重ね、付け根の印・速さ・向き・着せ替えを切りかえ）で行います。「胴体を 自動で あわせる」で胴体の位置と大きさを元の絵に合わせた下書きが出ます。ヒレ・脚・尾は元の絵と形がちがう（描きおこし）ので、目で見て決めています。

### いまの制限（素材がそろったら よくなること）

- パーツは元の絵と同じ **ななめ前向き** の絵です。真横・背面用の分割パーツ、背面の静止画は まだありません（用意できたら `back` に書く）
- ウミガメの頭は分かれていないので、胴体の絵の頭の部分を ぼかして切り出して上下させています（大きく拡大すると あごの下に うすい線が見えることがあります）
- 専用の見た目（甲羅・模様・貝殻）、最終段階の きらきら、困り顔の表情は パーツ表示には出ません（困り顔の 汗マークは出ます）

## 📍 ちず・ばしょの きろくは イベントの日だけ

ふだん家で使うときに **家の位置を記録しない** ため、ちず と ばしょ（GPS）の きろく は イベントの日だけ使えます（`js/event-mode.js`）。

- **開くしくみ（どちらか）**
  1. **日付**：`js/config.js` の `event.days` に書いた日は、0時〜24時、だれでも自動で開きます（いまは空）
  2. **受付の QR**：`operator.html` の「⓪ 受付用 QR」（アプリの URL`?event=あいことば`）を、スマホのカメラ、またはアプリの「ちず」→「うけつけの QRコードを よむ」で読むと、**その端末で その日の24時まで** 開きます。あいことばは読んだあと URL から消します（ブックマークやホーム画面に残さない）
  - あいことばは公開しているコードからも見えるので、鍵ではなく「うっかり家の位置を記録しない」ためのしくみです。変えるときは `event.openKey` を書きかえ、受付の QR も作り直してください
- **開いていないとき**：「ひろう」の記録で位置を聞きません・記録に位置を残しません。「ちず」は 🔒（「うけつけの QRコードを よむ」ボタン）。しゅるいべつの かず・きろくの いちらん は見られます
- **開いているとき**：ゴミを記録する **たびに**「📍 ばしょも きろく する？」と聞きます（写真をとったあと。写真なしのときは「きろく する！」を押したとき）。「きろく しない」なら その1件は位置なし
  - ブラウザで位置情報が「許可しない」になっているときは、iPhone／Android それぞれの許し方を出して「もういちど ためす」で試せます。**位置なしでも記録できます**（スマホのブラウザは、一度「許可しない」を選ぶとアプリから許可の画面を出し直せないため）
  - 位置を探すのは10秒まで。見つからなければ位置なしで記録します
- 設定（はぐるま）の「おうちの かたへ」に、いま使えるかどうかを表示します

## 🔒 データについて

- 育成・記録・写真・位置情報は **その端末のブラウザの中だけ** に保存されます（LocalStorage と IndexedDB）。アカウントは不要です
- **ブラウザのデータを消すと消えます。別のスマホ・別のブラウザには そのままでは引き継がれません**（設定の「おうちの かたへ」にも表示）。
  そのために **バックアップ** があります（SHIKA COLLECTION と同じ。`js/backup.js`）：設定 →「バックアップを ほぞん」で、育てた ようせい・記録・ゴミの写真・端末の設定を 1つのファイル（`clean-quest-backup-年月日.json`）にして端末に保存します。「バックアップから もどす」でファイルを選ぶと、中身（保存した日・ようせい・メダル・記録の数）を見せて2回たしかめてから、いまのデータと置き換えます。ほかのアプリのファイル・新しすぎる形・書きかえられた／こわれたファイル（チェックサムで検知。暗号ではありません）は理由を出して断り、いまのデータは変えません。ファイルはどこにも送信しません。運営画面のデータは含めません
- iPhone の Safari は、ホーム画面に追加していないサイトのデータを、長く使わないと自動で消すことがあります
- けいけんち・ポイント・レベルは、受け取った報酬と買った物の記録から毎回計算します（値を別々に持たないので食い違いません）
- 保存データが壊れていても、アプリは止まらずに最初から始めます（壊れたデータは `bct-state-broken` に控えを残します）
- 前の版（クリーンPt方式）の保存データは、クイズの正解とゴミの種類をミッションとして引き継ぎます
- 右上の はぐるま（設定）→「おうちの かたへ」→「さいしょから やりなおす」で全部消せます（2回確認します）
- 名前は文字として表示し、HTMLとして解釈しません
