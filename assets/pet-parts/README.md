# 泳ぐ・歩くためのパーツ原画

`preview-pet-parts.html` で3種類・3段階の元絵と57枚の透過PNGを確認できる。今回の成果物は描画素材。ゲーム本体の表示・動作・保存データは変更していない。

## 素材

- `assets/art-source/motion-parts/dolphin-parts-v1.png`：3段階 × 6パーツ。
- `assets/art-source/motion-parts/turtle-parts-v1.png`：3段階 × 6パーツ。
- `assets/art-source/motion-parts/hermit-parts-v2.png`：3段階 × 7パーツ。v1は不採用。
- `assets/pet-parts/*.png`：個別透過PNG、57枚。
- `assets/pet-parts/manifest.json`：種類・形態・パーツ名・原画の切り出し座標・寸法。
- `assets/pet-parts/pet-animation-parts-v1.zip`：個別PNG、manifest、本説明の配布用セット。
- `assets/art-source/motion-parts/generation-record.json`：内蔵image_genによる生成方法、採用プロンプト、参照原画。

既存の `assets/art-source/turnarounds/*-side-back-v1.png` も確認ページに掲載した。これは既存の向き資料であり、今回新しく分割したパーツは元絵と同じ斜め正面方向用。側面・背面専用の分割パーツは未作成。

## 分割と動かし方

| 種類 | 独立パーツ | 動作の組み立て |
| --- | --- | --- |
| イルカ | 顔・胴体、手前の胸びれ、奥の胸びれ、背びれ、尾の付け根、尾びれ | 胴体 → 尾の付け根 → 尾びれを親子でつなぎ、尾びれを少し遅らせて上下へ振る。胸びれは肩から回転させる。 |
| カメ | 顔・胴体・甲羅、左右の前びれ、左右の後ろびれ、しっぽ | 前びれで大きく水をかき、後ろびれは小さく姿勢を調整。肩の回転と面の縮みで水かき／戻しを描く。 |
| ヤドカリ | 顔・胴体・貝殻、左右のハサミ、手前の前後脚、奥の前後脚 | 対角の脚を組にして接地／持ち上げ／踏み出しを交互にする。各脚は絵の関節に合わせて2本のボーンを設定。ハサミは小さく揺らす。 |

奥側の手足 → 本体 → 手前側の手足の順に重ねる。付け根の丸い重なり部分は本体の下に隠す。ヤドカリ第3形態の大きなハサミは元絵の画面右（動物の左側）。反対向きへの転換時に左右の個性を反転させないこと。

## 実装時の調整

生成画像は元絵を参照した描き起こしであり、元画像を完全一致で切り離したものではない。隠れていた付け根は補完描写。全パーツの大きさ、取り付け位置、回転中心、重ね順は元絵と比較して調整し、組み立て後の見た目を確認してからゲームへ適用する。

個別PNGは `node tools/pack-motion-parts.mjs` で原画から抽出した。隣の絵が矩形に混ざることを避けるため、最大の連結シルエットと2pxのアンチエイリアス余白を保持する。原画は保存したまま、色の描き直し・変形・拡大縮小は行っていない。

まばたき用の目は、既存の通常顔／笑顔を用いる現行方式を引き継ぎ、今回の新しい胴体へ実装するときは目の位置を再調整する。
