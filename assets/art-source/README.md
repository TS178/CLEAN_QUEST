## 初回の制作記録

2026-10-10 に承認された「小学生がかわいいと思える」デザインを実装した素材です。キャラクターとアイテムは丸い体、大きな目、やわらかな頬、明るい海色とパステルカラーに統一しています。既存の画面 UI と共通アイコンは維持しています。

## 制作仕様

- 透明背景の手描き風 2.5D イラスト。輪郭はやわらかく、表面に穏やかな光沢。
- イルカ：アクアブルーとクリーム色のおなか。ウミガメ：ミント色、丸い甲羅、大きな顔。ヤドカリ：ピーチ色の体、ラベンダーとピーチの巻き貝、短い2本の目。
- 各種族は3段階の成長と通常・笑顔の2表情。
- 帽子・花・貝・王冠・アクセサリー・おもちゃは、単品でも読める明快な形と色。
- フレーム中央は透明。イベントフレーム上部の帯にはアプリ側で文字を重ねる。
- 模様は各種族の体・甲羅・貝に限定して重ね、顔を覆わない。

## アプリへの組み込み

`tools/pack-pet-art.mjs` が各素材を切り出して透明 WebP に保存し、`js/pet-sprites.js` にまとめます。色の変更や描き直しは行いません。切り出し範囲は `manifest.json`、出力寸法は JavaScript 内の各画像データに記録しています。

リポジトリのルートでローカルサーバーを起動し、`BCT_URL` をその URL に設定して `node tools/pack-pet-art.mjs` を実行してください。省略時は `http://127.0.0.1:8766/` を使います。Node.js と Microsoft Edge が必要です。

`js/pet-art.js` が種族・成長段階ごとの装着位置、表情、遊びのポーズ、模様のクリップ範囲を管理します。画像データを SVG 内に埋め込むため、写真保存とオフライン表示にも同じ絵を使えます。元画像 PNG と個別 WebP は制作保管用で、アプリは埋め込み済みの JavaScript のみ読み込みます。

アイテム ID、価格、ゲームのルール、保存データの形式は変更していません。
